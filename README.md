# Sharon's Birthday Celebration

A personal birthday website with a photo gallery, video memories, and a birthday note.

## View locally

Open `index.html` in a browser. Keep the `Sharon` folder alongside it so the local photos and videos load.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the root (`/`) folder, then save. GitHub Pages will publish `index.html` as the site homepage.
